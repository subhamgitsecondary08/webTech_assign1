Welcome to the Question Bank

This website provides previous year question papers, semester-wise course information and online examination forms for students of B.Tech.

Features

  • Student Registration
  • Semester-wise Course Structure
  • Online Question Papers
  • Group Blog
  • Photographs
  • Educational Videos

Instructions

  1. Complete the registration form before accessing the question bank.
  2. Select a subject from the navigation menu.
  3. Attempt the online question paper.
  4. Visit the Student Blog to read comments and opinions.

Important Notice

Note: This project is developed using only HTML as required in the assignment.
